Discovery overview

Discovery is the branch that checks what evidence exists, what has been exchanged, and what still needs to be produced.

Discovery states

  • Not started
  • Requested
  • Partially exchanged
  • Complete
  • Outstanding / disputed

What discovery affects

  • Pre-trial readiness
  • Trial bundle preparation
  • Evidence visibility
  • Compel / non-compliance options

Discovery summary

This summary should explain the discovery position in plain language and prepare the user for the next branch.

Example summary Discovery affidavit not yet filed. Financial records requested. Opponent has not responded fully. Compel may be required if delay continues.

Why this matters

Discovery is the gatekeeper for pre-trial and later trial readiness.

Where it goes next

If discovery is complete, the workflow should move to pre-trial. If not, show the compliance route first.

Questions panel

The user should be able to ask discovery questions directly from this page.

What if the other side ignores discovery?

The system should show a compliance warning and suggest the compel branch if the deadline has passed.

What documents should be disclosed?

The page should list the requested documents and mark the outstanding ones clearly.

Can this go to pre-trial now?

Only if the discovery branch is sufficiently complete and the dashboard health is no longer red or amber.

This discovery centre supports procedural assistance and access-to-justice guidance. It does not provide legal advice.
