1. Upload documents

Users should be able to add the core documents for the current matter. The system can later read and classify each upload.

Drop files here PDF, image, or scanned court document

Expected file types

  • Summons
  • Plea
  • Counterclaim
  • Reply
  • Settlement agreement
  • Discovery documents
  • Pre-trial notices
  • Set-down notices

What the system extracts

  • Case number
  • Parties
  • Dates
  • Court name
  • Document type
  • Missing items

4. Court procedure support

The document centre should also guide the user on what to do if a paper is filed, stamped, rejected, or still missing.

Filing-related checks

  • Stamped copy available?
  • Court Online access confirmed?
  • Physical filing required?
  • Set-down email needed?

Warnings

  • Deadline close
  • Missing signature
  • Unreadable scan
  • Wrong court format

5. Questions panel

The user should be able to ask what each document means and what it affects in the case.

What document am I missing?

The system should compare the active case stage to the uploads and highlight the missing item.

Why is my document unreadable?

The system should flag poor scans, blurry text, or incomplete pages so the user can re-upload a better copy.

What if settlement is complete?

The dashboard can shift to a settlement-ready path and reduce the later hearing-prep burden.

This document centre is part of procedural assistance and access-to-justice support. It does not provide legal advice.
