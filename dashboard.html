2. Case health summary

The dashboard should show the state of every case using simple visual signals.

Red signals

  • Deadline close
  • Missing filing confirmation
  • Unanswered summons
  • Discovery overdue

Amber signals

  • Settlement incomplete
  • Family Advocate pending
  • Set-down not confirmed
  • Bundle incomplete

Green signals

  • Documents complete
  • Stage aligned
  • Ready for hearing prep
  • Settlement approved

Dashboard outputs

  • Current stage
  • Next step
  • Health score
  • Readiness status

4. Court Online / filing support

For supported matters, the dashboard should surface filing mode, access status, and whether the user needs to go in person for help or confirmation.

Filing status

  • Court Online access: yes / no
  • Stamped copy: yes / no
  • Physical filing needed: yes / no
  • Email set-down required: yes / no

Support actions

  • Ask how to file
  • Show what to take
  • Show where to go
  • Escalate if urgent

5. Questions panel

The dashboard should allow a user to ask about the next step without leaving the case view.

What should I do next?

The dashboard should point to the next open branch based on stage, deadlines, and unresolved issues.

Why is this case red?

The case health score should explain missing filings, deadline pressure, or incomplete settlement and children steps.

Can I settle now?

If the settlement branch is complete, the system should allow a settlement-ready or unopposed-ready status.

This dashboard is a procedural workflow view, not legal advice. It should help users understand where each matter stands and what needs attention first.
