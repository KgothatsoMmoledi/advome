What the portal will do

  • Identify the current procedural stage
  • Show the next step in plain language
  • Track missing documents and deadlines
  • Show settlement and children flags where relevant
  • Support a case-health score for each matter
  • Prepare users for hearing or trial
Best current path For the live build, use Divorce, CCMA / Labour, and Estates as the active self-represented workflows, then use the dashboard to monitor every matter.
What to do first Pick the matter type, then use the linked workflow page to move through the case state.
What to avoid Do not leave core workflow buttons as “Coming Soon” for modules that already exist.

Roadmap

The first working modules are Divorce, CCMA / Labour, Estates Administration, Dashboard, and Attorney Portal. Other matters can be added later without changing the main structure.

Advome supports access to justice, procedural clarity, and practical case navigation across matters.
