Questions

The user should be able to ask practical set-down questions directly here.

How do I draft a Notice of Set Down?

The page should guide the user through the case number, date, parties, and service details needed for the notice.

Must the Notice of Set Down be served?

Yes. The workflow should show service as a required step before enrolment and allocation progress.

What proof of service is required?

The page should prompt the user to upload a stamped return, affidavit, or other acceptable proof.

What if the registrar ignores emails?

The page should move to follow-up and, if needed, escalation to the court manager.

Can I speak to the court manager?

The page should allow escalation guidance when registrar responses are delayed.

Who is the Judicial Case Manager?

The page should keep this as an allocation field so the user sees whether a judicial manager has been assigned.

Set-down summary

Keep the summary short and procedural.

The matter has progressed beyond pre-trial and is substantially ready for enrolment. A Notice of Set Down must be drafted, served and filed. Trial allocation remains outstanding and communication with the registrar should continue until a date is allocated.
